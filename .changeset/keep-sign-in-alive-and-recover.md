Sign-in now stays active while you retrieve your emailed code and offers a clear way to restart if it times out.

**Affects:** End users

**End users:** Previously, taking more than about five minutes to enter a code could leave the surrounding sign-in expired even though the code was still valid. The code-entry page now keeps the sign-in active while it remains open. If browser suspension or a longer interruption still makes the sign-in unrecoverable, the page disables code entry, hides **Resend code** and **Use different email**, and shows **Start over**; clicking it returns to the app you came from so you can begin again.
